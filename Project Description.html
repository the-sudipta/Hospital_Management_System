Hospital Management System

Project Overview

This project aims to create a secure access control system for PACS, RIS, and HIS using HTML, CSS, JavaScript, and PHP.

Users & Roles

  • Administrator: Full access to all systems (PACS, RIS, HIS).
  • Doctor: Can access patient records, prescribe treatments, and view medical history.
  • Radiologist: Manages PACS, interprets radiology images, and submits reports.
  • Receptionist: Handles appointment scheduling and patient registrations.
  • Billing Staff: Manages hospital billing and financial records.

System Features

  • HIS:
    • CRUD Patient table
    • Create Appointment
    • Create Bill
    • Dashboard
    • Extra: View my records, View my profile
  • RIS:
    • Create test schedule
    • Create Report
    • View Reports (CRUD)
    • Dashboard
    • Extra: View my profile
  • PACS:
    • Create/Upload test images
    • View all images
    • Extra: View my profile
  • Admin:
    • Add User
    • CRUD Patient + View List
    • CRUD Appointment + View List
    • CRUD Bill + View List
    • CRUD Schedule + View List
    • CRUD Report + View List
    • CRUD Images + View List
